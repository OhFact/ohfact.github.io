Projects

HSX Coil Forces: Coil Forces.
This code aims to calculate the magnetic field and forces created by a set of coils (stellarator or tokamak) by using the method outlined in "Efficient calculation of self magnetic field, self-force, and self-inductance for electromagnetic coils. II. Rectangular cross-section", Landreman and Hurwitz (2023). It adds additional diagnostics and plots to the work that is done in the paper, and was written in order to run a solidworks simulation on HSX using the results.

Spring 26 Physics 525 Plasma Physics Final Project: Hyperresistive Reconnection.
This code uses the MHX codebase to replicate scaling laws and other such results from "Magnetic reconnection mediated by hyper-resistive plasmoid instability", Yi-Min Huang, A. Bhattacharjee, and Terry G. Forbes.
